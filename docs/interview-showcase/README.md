# Delegation Decoded: interview showcase

**Start with the reader’s task: find a congressional record and understand what it says.**

This is the backup to Open Cabinet for the Houston Chronicle Round 4 prompt. It also works as a short second exhibit for reader-facing AI answers.

1. [Walkthrough](walkthrough.md): the explanation, one stage at a time, with code to open.

2. [Interview context](interview-context.md): what the panel requested and what Trevor already discussed.

3. [Hardening report](hardening-report.md): changes, actual verification results, and unresolved limits.

Practice the first three stages before learning provider details. After each stage, explain what happens, what checks it, and what a person still decides.

**Do not call the project foolproof.** A valid citation proves a connection to a retrieved record; it does not prove the answer’s interpretation is correct.
